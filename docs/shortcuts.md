# Keyboard shortcuts

`?` in the app lists them all; Ctrl+Shift+P (or F1) runs any command by name. On macOS, Ctrl is Cmd. In VS Code, the diagram's shortcuts win over VS Code's while it has the focus.

## File

| Shortcut     | Command        |
| ------------ | -------------- |
| Alt+N        | New project    |
| Ctrl+O       | Open…          |
| Ctrl+S       | Save           |
| Ctrl+Shift+S | Save as…       |
| Ctrl+Alt+S   | Save all       |
| Alt+W        | Close document |
| Ctrl+Alt+G   | Generate code  |

## Edit

| Shortcut                 | Command            |
| ------------------------ | ------------------ |
| Ctrl+Z                   | Undo               |
| Ctrl+Y, Ctrl+Shift+Z     | Redo               |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut / copy / paste |
| Ctrl+D                   | Duplicate          |
| Delete, Backspace        | Delete             |
| Ctrl+A                   | Select all         |
| Escape                   | Clear selection    |
| F2                       | Rename module      |
| Arrows (Shift: further)  | Move the selection |

## Insert

| Shortcut | Command       |
| -------- | ------------- |
| Ctrl+M   | Add module    |
| Alt+M    | Add submodule |
| Alt+I    | Add in port   |
| Alt+O    | Add out port  |

## View

| Shortcut         | Command                              |
| ---------------- | ------------------------------------ |
| Ctrl+Shift+P, F1 | Command palette                      |
| Ctrl+P           | Go to…                               |
| Alt+← / Alt+→    | Previous / next selection            |
| F / Shift+F      | Fit selection / fit all              |
| + (=) / -        | Zoom in / out                        |
| Ctrl+0           | Zoom 100%                            |
| Alt+G            | Open project view                    |
| Alt+Enter        | Open module in its own view          |
| Alt+U            | Edit as text                         |
| H / Shift+H      | Hide selection / show hidden modules |
| Alt+Z            | Word wrap (text editor)              |

## Arrange

| Shortcut   | Command                                 |
| ---------- | --------------------------------------- |
| Ctrl+Alt+L | Auto-arrange (selection content / view) |
| Ctrl+Alt+H | Auto-arrange horizontally               |
| Ctrl+Alt+V | Auto-arrange vertically                 |
| Ctrl+G     | Group into a module                     |
| Ctrl+L     | Lock position and size                  |

## Window

| Shortcut                  | Command                  |
| ------------------------- | ------------------------ |
| Ctrl+I                    | Inspector                |
| Ctrl+Shift+M              | Problems                 |
| Ctrl+Shift+U              | Output                   |
| Ctrl+Shift+F              | Search                   |
| Ctrl+,                    | Settings                 |
| Alt+1…9                   | Document 1…9             |
| Alt+PageUp / Alt+PageDown | Previous / next document |
| ?                         | Keyboard shortcuts       |

## Panels and text editor

| Shortcut                          | Where                             | Action                   |
| --------------------------------- | --------------------------------- | ------------------------ |
| Alt+↑ / Alt+↓                     | Explorer, Code generation         | Move the focused section |
| Ctrl+F / Ctrl+H                   | Text editor                       | Find / replace           |
| Ctrl+Space                        | Text editor                       | Completion               |
| Ctrl+S                            | Template, generated file, IDL tab | Save the file            |
| Alt+click                         | Code generation                   | Open a file to the side  |
| Double-click / Shift+double-click | Canvas                            | Zoom in / out            |
| Alt while dragging a bend         | Canvas                            | No snapping              |
